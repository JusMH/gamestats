# Análisis funcional — Scala

Este módulo recibirá eventos preparados por Go y calculará estadísticas por jugador, partida y otras agregaciones definidas por el equipo. Aplicará transformaciones de colecciones y detectará patrones que requieran relacionar distintos eventos.

Los resultados deberán entregarse en formato estructurado y consultable.
