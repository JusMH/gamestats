# Fuente de eventos simulados

El proyecto no exige desarrollar videojuegos. Esta carpeta alojará una fuente simulada con eventos de distintas partidas, jugadores y situaciones, incluyendo partidas de juegos diferentes en paralelo.

Se incluirán casos normales, inválidos y casos pensados para comprobar reglas basadas en secuencias.
